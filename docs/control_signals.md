# Control Unit & ALU Control Truth Tables

This document details the architectural control signals generated by the Main Decoder (`mips_decoder.v`) and the ALU Control Unit (`alu_control.v`) for the Single-Cycle MIPS Processor.

---

## 1. Main Decoder Control Signals Truth Table

| Instruction | Type | Opcode (hex) | Opcode (bin) | `RegDst` | `ALUSrc` | `MemToReg` | `RegWrite` | `MemRead` | `MemWrite` | `Branch` | `Jump` | `ALUOp` | `invalid_opcode` |
|---|---|---|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **ADD** | R | `0x00` | `000000` | 1 | 0 | 0 | 1 | 0 | 0 | 0 | 0 | `10` | 0 |
| **SUB** | R | `0x00` | `000000` | 1 | 0 | 0 | 1 | 0 | 0 | 0 | 0 | `10` | 0 |
| **AND** | R | `0x00` | `000000` | 1 | 0 | 0 | 1 | 0 | 0 | 0 | 0 | `10` | 0 |
| **OR** | R | `0x00` | `000000` | 1 | 0 | 0 | 1 | 0 | 0 | 0 | 0 | `10` | 0 |
| **XOR** | R | `0x00` | `000000` | 1 | 0 | 0 | 1 | 0 | 0 | 0 | 0 | `10` | 0 |
| **SLT** | R | `0x00` | `000000` | 1 | 0 | 0 | 1 | 0 | 0 | 0 | 0 | `10` | 0 |
| **ADDI** | I | `0x08` | `001000` | 0 | 1 | 0 | 1 | 0 | 0 | 0 | 0 | `00` | 0 |
| **LW** | I | `0x23` | `100011` | 0 | 1 | 1 | 1 | 1 | 0 | 0 | 0 | `00` | 0 |
| **SW** | I | `0x2B` | `101011` | X (0) | 1 | X (0) | 0 | 0 | 1 | 0 | 0 | `00` | 0 |
| **BEQ** | I | `0x04` | `000100` | X (0) | 0 | X (0) | 0 | 0 | 0 | 1 | 0 | `01` | 0 |
| **J** | J | `0x02` | `000010` | X (0) | X (0) | X (0) | 0 | 0 | 0 | 0 | 1 | `00` | 0 |
| **Illegal / Default** | — | Other | Other | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | `00` | **1** |

> **Note on Safety:** When `invalid_opcode` is asserted, all state mutation signals (`RegWrite`, `MemWrite`, `MemRead`, `Branch`, `Jump`) are forced to 0, ensuring an unhandled instruction behaves as a harmless NOP without altering register or memory states.

## 2. ALU Control Truth Table

The ALU Control Unit takes the 2-bit `ALUOp` from the main decoder and the 6-bit `funct` field from `instruction[5:0]`.

| Instruction | `ALUOp[1:0]` | Funct (bin) | Funct (hex) | Operation Name | `alu_ctrl[3:0]` | `invalid_funct` |
|---|:---:|:---:|:---:|---|:---:|:---:|
| **LW** | `00` | XXXXXX | — | ADD (Address calculation) | `0010` | 0 |
| **SW** | `00` | XXXXXX | — | ADD (Address calculation) | `0010` | 0 |
| **ADDI** | `00` | XXXXXX | — | ADD (Immediate addition) | `0010` | 0 |
| **BEQ** | `01` | XXXXXX | — | SUB (Equality subtraction) | `0110` | 0 |
| **ADD** | `10` | `100000` | `0x20` | Addition | `0010` | 0 |
| **SUB** | `10` | `100010` | `0x22` | Subtraction | `0110` | 0 |
| **AND** | `10` | `100100` | `0x24` | Bitwise AND | `0000` | 0 |
| **OR** | `10` | `100101` | `0x25` | Bitwise OR | `0001` | 0 |
| **XOR** | `10` | `100110` | `0x26` | Bitwise XOR | `0011` | 0 |
| **SLT** | `10` | `101010` | `0x2A` | Signed Set on Less Than | `0111` | 0 |
| **Invalid Funct** | `10` | Other | Other | NOP / Inactive | `1111` | **1** |

## 3. ALU Operation Code Summary

| Control Code (`alu_ctrl`) | Operation Performed | Verilog Expression | Zero Flag Active Condition |
|:---:|---|---|---|
| `4'b0000` | Bitwise AND | `result = a & b` | `result == 32'd0` |
| `4'b0001` | Bitwise OR | `result = a \| b` | `result == 32'd0` |
| `4'b0010` | Signed / Unsigned Addition | `result = a + b` | `result == 32'd0` |
| `4'b0011` | Bitwise Exclusive-OR | `result = a ^ b` | `result == 32'd0` |
| `4'b0110` | Subtraction | `result = a - b` | `result == 32'd0` (asserts on $a == b$) |
| `4'b0111` | Signed Comparison (SLT) | `result = ($signed(a) < $signed(b)) ? 1 : 0` | `result == 32'd0` (asserts when $a \ge b$) |
| `4'b1111` | Safe Default | `result = 32'd0` | `1'b1` |
